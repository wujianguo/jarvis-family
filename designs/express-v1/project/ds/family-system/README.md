# Jarvis Family

家里的快递，一起照看。视觉以清晰、安稳、易读为原则：白底和浅灰绿承载信息，深绿只用于主操作，暖橙提示“待取”，完成态用浅绿。小程序与 Web 共用颜色、字号节奏和圆角；取件码始终比辅助信息更醒目。

## 使用规则

- 页面背景用 `canvas`，容器用 `surface`，正文用 `ink`，次要说明用 `muted`。
- 主按钮用 `brand`，待取提示用 `pending` 与 `pending-tint`；完成提示用 `brand` 与 `brand-tint`。状态同时写文字，不只靠颜色。
- 44px 是最小触控高度；卡片与按钮采用 12px 左右的圆角。表格以线条分隔，少用阴影。
- 字体使用系统无衬线中文回退栈，取件码使用较粗字重与适度字间距。

这是一版为原型新建的小型设计系统，尚无既有品牌素材或 Logo。字标只用文字。
